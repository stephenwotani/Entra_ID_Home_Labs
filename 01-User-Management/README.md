# Microsoft Entra ID: User Management

## 📌 Project Overview
This project demonstrates user identity administration in Microsoft Entra ID. It covers creating, configuring, managing, and maintaining user accounts throughout their identity lifecycle.

## 🎯 Objectives
- Create and manage cloud-based user accounts.
- Configure user properties and identity attributes.
- Manage account status and authentication.
- Perform user onboarding and offboarding.
- Apply identity administration best practices.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Microsoft Entra Admin Center

## ⚙️ Implementation

1. Created a new cloud user account.
2. Configured username (UPN) and display name.
3. Updated user profile and organizational attributes.
4. Assigned usage location.
5. Reset user password.
6. Blocked and unblocked user sign-in.
7. Explored account deletion and restoration.

## 🔐 Security Considerations
- Enforce strong authentication.
- Apply least privilege.
- Disable accounts when access is no longer required.
- Avoid assigning unnecessary administrative permissions.
