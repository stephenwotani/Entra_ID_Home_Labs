# Microsoft Entra ID: Group Management

## 📌 Project Overview
This project demonstrates group administration in Microsoft Entra ID, focusing on centralized access management, group membership, and organizational resource assignment.

## 🎯 Objectives
- Create and manage security groups.
- Understand Microsoft 365 groups.
- Assign and remove group members.
- Explore group ownership.
- Understand dynamic membership.
- Implement group-based access management.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Microsoft Entra Admin Center

## ⚙️ Implementation

1. Created security groups.
2. Configured group names and descriptions.
3. Added and removed users from groups.
4. Assigned group owners.
5. Explored Microsoft 365 groups.
6. Configured or examined dynamic membership rules (where licensed).
7. Explored group-based licensing (where available).

- Verified successful group creation.
- Confirmed users were added and removed correctly.

## 🔐 Security Considerations
- Use security groups to simplify access management.
- Review group membership regularly.
- Restrict group ownership appropriately.
- Apply least privilege to assigned resources.

Learned how groups simplify identity administration, improve scalability, and support centralized access management.
