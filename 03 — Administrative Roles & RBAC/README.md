# Microsoft Entra ID: Administrative Roles & RBAC

## 📌 Project Overview
This project explores Role-Based Access Control (RBAC) in Microsoft Entra ID, demonstrating how administrative permissions are assigned and managed securely.

## 🎯 Objectives
- Understand Microsoft Entra built-in roles.
- Assign administrative roles to users.
- Explore role permissions and scope.
- Implement the principle of least privilege.
- Understand the risks of excessive administrative access.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Microsoft Entra Admin Center
- Role-Based Access Control (RBAC)

## ⚙️ Implementation

1. Explored available Microsoft Entra built-in roles.
2. Reviewed Global Administrator permissions.
3. Assigned appropriate administrative roles to test users.
4. Explored User Administrator and Helpdesk Administrator.
5. Examined Security Administrator and Authentication Administrator.
6. Removed role assignments.
7. Compared role permissions and responsibilities.

## 🧪 Testing & Validation
- Verified role assignment.
- Confirmed administrative role visibility.
- Reviewed role permissions.
- Tested administrative access using a designated test account where possible.

## 🔐 Security Considerations
- Avoid permanent Global Administrator assignments.
- Assign only necessary roles.
- Separate administrative and standard user accounts.
- Regularly review privileged assignments.

## 📚 Key Learnings
Developed an understanding of RBAC, administrative delegation, privilege management, and least-privilege implementation.
