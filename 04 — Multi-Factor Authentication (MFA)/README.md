# Microsoft Entra ID: Multi-Factor Authentication (MFA)

## 📌 Project Overview
This project demonstrates the implementation and administration of Multi-Factor Authentication in Microsoft Entra ID to strengthen identity verification and reduce account compromise risks.

## 🎯 Objectives
- Understand MFA and its security benefits.
- Configure authentication methods.
- Explore Microsoft Authenticator.
- Enforce additional authentication requirements.
- Validate MFA registration and authentication.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Microsoft Authenticator
- Microsoft Entra Authentication Methods

## ⚙️ Implementation

1. Reviewed authentication methods available in Microsoft Entra ID.
2. Configured authentication methods policy.
3. Enabled appropriate authentication methods for test users.
4. Registered authentication methods for a test account.
5. Explored MFA enforcement options.
6. Tested authentication with additional verification.
7. Reviewed authentication-related sign-in logs.

## 🧪 Testing & Validation
- Verified authentication method registration.
- Tested sign-in with additional verification.
- Confirmed authentication behavior.
- Reviewed relevant sign-in events.

## 🔐 Security Considerations
- Require MFA for privileged accounts.
- Prefer phishing-resistant authentication where supported.
- Avoid relying on SMS as the strongest authentication method.
- Maintain secure recovery methods.

## 📚 Key Learnings
Developed practical understanding of modern authentication, MFA administration, authentication methods, and identity security controls.
