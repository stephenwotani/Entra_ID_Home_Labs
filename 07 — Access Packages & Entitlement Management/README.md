# Microsoft Entra ID: Entitlement Management & Access Packages

## 📌 Project Overview
This project explores Microsoft Entra entitlement management, demonstrating how access packages can simplify resource access requests, approvals, assignments, and lifecycle management.

## 🎯 Objectives
- Understand identity governance.
- Create and manage catalogs.
- Configure access packages.
- Define resource access.
- Configure approval workflows.
- Explore access expiration and reviews.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Microsoft Entra Entitlement Management
- Access Packages

## ⚙️ Implementation

1. Accessed entitlement management.
2. Created an access catalog.
3. Added resources to the catalog.
4. Created an access package.
5. Configured group or application resource access.
6. Defined access request policies.
7. Explored approval workflows.
8. Configured expiration settings.
9. Tested the access request and approval process.

## 🧪 Testing & Validation
- Verified catalog and package creation.
- Tested access request submission.
- Reviewed approval workflow.
- Confirmed access assignment and expiration settings.

## 🔐 Security Considerations
- Require approval for sensitive resources.
- Limit access duration.
- Review assignments regularly.
- Remove unnecessary access.
- Apply least privilege.

## 📚 Key Learnings
Learned how entitlement management supports scalable access governance, controlled resource access, and identity lifecycle management.
