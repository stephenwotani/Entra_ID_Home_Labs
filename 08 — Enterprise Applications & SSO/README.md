# Microsoft Entra ID: Enterprise Applications & Single Sign-On

## 📌 Project Overview
This project demonstrates enterprise application administration in Microsoft Entra ID, focusing on application integration, access assignment, and Single Sign-On (SSO).

## 🎯 Objectives
- Understand enterprise applications.
- Configure application access.
- Explore Single Sign-On.
- Understand SAML-based authentication.
- Manage application user assignments.
- Review application permissions.

## 🛠️ Technologies Used
- Microsoft Entra ID
- Enterprise Applications
- SAML 2.0
- Single Sign-On (SSO)

## ⚙️ Implementation

1. Accessed Enterprise Applications.
2. Added or explored a test application.
3. Configured user and group assignments.
4. Explored SSO configuration.
5. Reviewed SAML configuration parameters where applicable.
6. Examined application access and authentication.
7. Tested application sign-in using a test account.
