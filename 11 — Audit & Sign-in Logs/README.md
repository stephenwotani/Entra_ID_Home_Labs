
# Microsoft Entra ID Audit Logs & Sign-in Log Investigation

**Domain:** Security Monitoring & Investigation  
**Platform:** Microsoft Entra ID  
**Project Type:** Log Analysis Lab  


## 1. Project Overview

This project demonstrates how Microsoft Entra audit and sign-in logs can be used to monitor administrative activities, investigate authentication events, and support identity-related security investigations.

## 2. Objectives

- Navigate audit and sign-in logs.
- Filter events by user, activity, status, and time.
- Interpret relevant log fields.
- Investigate successful and failed sign-ins.
- Document an evidence-based investigation.

## 3. Tools Used

- Microsoft Entra Admin Center
- Audit Logs
- Sign-in Logs
- Test users
- Microsoft Excel or other analysis tools, if used

## 4. Implementation Steps

1. Navigate to Microsoft Entra audit logs.
2. Identify a known administrative activity.
3. Filter logs by activity and time range.
4. Inspect the event details.
5. Navigate to sign-in logs.
6. Investigate a successful or failed authentication.
7. Review available details, including status and authentication information.
8. Document findings and a brief investigation timeline.


## 9. Conclusion

This lab demonstrates how Entra audit and sign-in logs support identity monitoring, administrative auditing, and security investigations.
