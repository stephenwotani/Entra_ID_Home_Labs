
# Microsoft Entra ID Password Management & Self-Service Password Reset

**Domain:** Identity Administration & Security  
**Platform:** Microsoft Entra ID  
**Project Type:** Identity Lifecycle Lab  

## 1. Project Overview

This project explores Microsoft Entra password management and Self-Service Password Reset (SSPR), focusing on password recovery, authentication requirements, and secure account recovery workflows.

## 2. Objectives

- Understand password management capabilities.
- Configure or review SSPR.
- Understand SSPR scope and authentication methods.
- Test password recovery using a test account.
- Explore hybrid password writeback concepts.

## 3. Tools Used

- Microsoft Entra Admin Center
- Self-Service Password Reset
- Authentication Methods
- Test user accounts

## 4. Implementation Steps

1. Review password management options.
2. Check SSPR availability and licensing.
3. Review SSPR scope and authentication methods.
4. Configure a limited test scope where permitted.
5. Register a test user for password reset.
6. Perform a controlled password reset.
7. Verify the expected result.
8. Explore hybrid password writeback requirements if applicable.

## 6. Testing & Validation

- Confirm the test account is within scope.
- Verify authentication requirements.
- Test the password reset workflow.
- Confirm the expected result.
- Document any limitations or issues.

## 7. Security Considerations

- Never publish passwords, reset links, or verification codes.
- Use test accounts.
- Apply appropriate authentication requirements.
- Do not weaken production password policies.
- Understand hybrid password writeback prerequisites.

## 8. Lessons Learned

Document SSPR configuration, troubleshooting, and account recovery insights.

## 9. Conclusion

This lab demonstrates how self-service password reset can improve user experience while maintaining secure identity recovery controls.
