## 📚 Core Security Principles

Throughout these projects, I focus on applying the following security principles:

- **Least Privilege:** Users receive only the permissions required to perform their responsibilities.
- **Zero Trust:** Access is continuously evaluated rather than implicitly trusted.
- **Defense in Depth:** Multiple security controls work together to protect identities.
- **Separation of Duties:** Critical responsibilities are distributed to reduce risk.
- **Privileged Access Security:** Administrative privileges are controlled, monitored, and limited.
- **Identity Governance:** Access is reviewed and managed throughout the identity lifecycle.
